Exercise 2: HTML Form #2 (POST Method)

Form Information:

  • Method: POST
  • Action: ex2.html (same file)
  • Input Fields: name (text), message (textarea)

📍 Answer: Where will the sent data appear?

The sent data will appear in the Network Tab of the browser's Developer Tools!

Why? When using the POST method:

  • Form data is sent in the request body, not in the URL
  • Data is not visible in the browser's address bar
  • You need to inspect the Network Tab to see the data
  • Data is transmitted securely (not exposed in URL)

🔍 How to View POST Data:

  1. Open Developer Tools: Press F12 or right-click → Inspect
  2. Go to Network Tab: Click on the "Network" tab
  3. Clear existing requests: Click the clear button (🗑️)
  4. Submit the form: Fill out and submit the form above
  5. Look for the request: Find "ex2.html" in the list
  6. Click on the request: View details
  7. Check "Request" or "Payload": See the form data there!

GET Method (Exercise 1)

  • Data in URL parameters
  • Visible in address bar
  • Limited data size
  • Cached by browsers
  • Good for searches, filters

POST Method (Exercise 2)

  • Data in request body
  • Hidden from URL
  • Larger data capacity
  • Not cached by default
  • Good for forms, uploads

🎯 Key Differences from Exercise 1:

  • URL stays clean: No query parameters added
  • Data is hidden: Form data not visible in address bar
  • More secure: Data not exposed in browser history
  • Network inspection required: Use DevTools to see the data
