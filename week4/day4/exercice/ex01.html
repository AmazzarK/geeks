Exercise 1: HTML Form

Form Information:

  • Method: GET
  • Action: ex01.html (same file)
  • Input Fields: name (text), message (textarea)

📍 Answer: Where will the sent data appear?

The sent data will appear in the URL (address bar) as query parameters!

Why? When using the GET method:

  • Form data is appended to the URL as query string parameters
  • Data is visible in the browser's address bar
  • Format: filename.html?name=value&message=value

Example: If you enter "John" as name and "Hello World" as message, the URL will look like:

ex01.html?name=John&message=Hello+World

Note: Spaces and special characters are URL-encoded (e.g., space becomes +)
